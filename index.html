04 / GUIDE

Understand the boundaries

01

What gets checked

Measure naming conventions, bracket references, matching in-paste dependencies, suspicious constructs, basic delimiter errors and function usage. These are review prompts—not errors proven by a semantic model.

02

What is not tested

No semantic validation, DAX execution, relationship inspection, filter-context evaluation, actual query plans or performance benchmarks. Use Power BI DAX Query View or DAX Studio with your model to test the real result.

03

Supported inputs

Paste regular measures, DEFINE MEASURE blocks, simple Name = expression definitions, or plain expressions. Import .dax, .tmdl or .txt. Complex TMDL projects and full-language parsing are outside this release.

05 / TRUST & PORTABILITY

Your measures. Your machine.

Read how this static application works and independently inspect its requests.

Local processing

All input, files, formatting, comparison and analysis run in JavaScript inside your browser. Nothing is uploaded to Mightora by this app. The online edition loads external shared UI and brand assets; that does create resource requests.

Network transparency

Resource Timing information appears here once loaded.

This is a best-effort Resource Timing summary, not a complete network monitor or independent audit. It may omit requests, including browser extensions or cross-origin details.

Verify independently

  1. Press F12 (or open browser Developer Tools).
  2. Select the Network tab and enable Preserve log.
  3. Reload this app and inspect requests and domains.
  4. Paste a measure and analyse again. Confirm no measure submission requests occur.
